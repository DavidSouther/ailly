# Refactor Plan: tool_round_trip uses NoopModel

Context: working directory carries the in-progress feat_tools branch. Test `engine_tool_round_trip` is currently green using a hand-rolled `FakeModel` (a `rig::completion::CompletionModel`) wrapped in `RigEngine`. We want the test to drive `Noop` directly so the test no longer depends on rig's streaming-tool-call plumbing or a bespoke fake.

Reference shapes:
- `typescript/core/src/engine/noop.ts` matches `USE <tool> WITH <args>` in the last message and emits a tool-use debug record.
- `typescript/integ/20_tools/mcp.sh` exercises the round-trip end-to-end with the same `USE / TOOL RETURNED` envelope.

This is structural addition, not behavior change for existing callers (envelope path is unchanged when no `USE` token appears).
