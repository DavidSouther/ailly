# Candidate project: a TypeScript React app

This is the codebase whose comments you are reviewing. It is a TypeScript React
application. Components read their data from context providers and take the usual
presentational props, and the code carries DocBlocks on its public symbols and
the occasional inline note.

Your task is a **comment review**, not a code review. Read the comments in the
material you are given and report on them. Produce a critique document: for each
comment, say whether it earns its place and why. Do not rewrite the code, and do
not comment on whether the code itself is correct or well-structured. The artifact
is the review.
