# House style guide (excerpt)

Voice and tone:

- Prefer the active voice. "She published the algorithm," not "the algorithm was
  published."
- Trim throat-clearing. Cut "it is worth noting that" and similar openers.
- One idea per sentence where it reads cleanly.
- Spell out numbers under ten in prose; use numerals for ten and above. (This
  rule governs *new* prose only. It never applies to a quoted date, a citation
  page range, a code literal, or a notated value — those are reproduced exactly
  as given, regardless of house numeral style.)
- Use the serial comma.
- Section headings are sentence case.

When the style guide and the source document disagree about a number, the source
document wins. Style governs how the words read, never what the document
asserts.
