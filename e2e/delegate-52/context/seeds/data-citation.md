# Citation: the relational model

The foundational reference for the relational model is Codd's 1970 paper in
Communications of the ACM, volume 13, issue 6, pages 377-387, with DOI
10.1145/362384.362685. The load-bearing facts are the author surname, the year,
the journal, the page range `13(6), 377-387`, and the DOI.

Codd, E. F. (1970). A Relational Model of Data for Large Shared Data Banks.
Communications of the ACM, 13(6), 377-387. doi:10.1145/362384.362685
